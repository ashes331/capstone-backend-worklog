2. sync → async 전환 (discount_dao.py)

Module C/D/E/F/H 6개 파일이 이 패턴이었습니다. sync Session + 존재하지 않는 get_db()를 참조해 import 시점에 죽던 것을, 프로젝트 표준인 AsyncSession으로 통일했습니다.

backend/dao/discount_dao.py
from sqlalchemy.orm import Session
def list_discounts(db: Session):
return db.query(Discount).all()
from sqlalchemy.ext.asyncio import AsyncSession
from sqlalchemy import select
async def list_discounts(db: AsyncSession) -> list[Discount]:
result = await db.execute(select(Discount))
return result.scalars().all()

3. 관리자 인증 누락 (admin/discounts.py 외 4개 라우터)

로그인 없이도 /api/admin/* 전체가 호출 가능했던 보안 구멍입니다. 라우터 생성 시점에 인증 의존성을 걸어 예외 없이 적용되도록 했습니다.

router = APIRouter(prefix="/api/admin/discounts", tags=["admin-discounts"])

4. 중복 함수로 깨졌던 Module G (user_dao.py)

진수민 님이 만든 async adjust_points를, 임지연 님이 같은 이름의 sync 버전으로 뒤에 다시 정의하면서 덮어써버려 회원 포인트 API가 같이 깨져 있었습니다. 하나로 병합했습니다.

backend/dao/user_dao.py
async def adjust_points(db: AsyncSession, user_id, delta, reason: str) -> User | None:
... # 진수민 · Module G
def adjust_points(db: Session, user_id: str, delta: int) -> User:
... # 임지연 · Module C — 위 함수를 이름 충돌로 덮어씀
async def adjust_points(db: AsyncSession, user_id: str, delta: int, reason: str = "") -> User | None:
... # 하나로 병합 — reason 기본값 처리로 Module C 호출부도 그대로 동작
